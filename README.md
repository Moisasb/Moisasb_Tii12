# Portfólio de atividades — Técnico em Informática para Internet

Repositório de estudos desenvolvido durante o curso Técnico em Informática para Internet. Reúne exercícios e pequenas aplicações criadas para praticar fundamentos de desenvolvimento web, programação e construção de interfaces.

## Conteúdo do repositório

### HTML e estruturação
- Páginas com textos, listas, tabelas, links, imagens e formulários.
- Exercícios de estruturação de conteúdo.
- Página de cardápio e atividades de tabela e formulário.

### CSS e layout
- Seletores e propriedades de estilização.
- Posicionamento e organização com Flexbox.
- Exercícios de layout e página responsiva.
- Estilização de componentes e páginas.

### JavaScript
- Exercícios de fundamentos da linguagem.
- Operadores, variáveis, condições e estruturas de repetição.
- Manipulação do DOM e eventos.
- Exercícios de revisão e acessibilidade.

## Organização

As atividades estão agrupadas por assunto e etapa de estudo, com pastas específicas para HTML, CSS e JavaScript. Alguns exercícios possuem seus próprios arquivos de estilo, scripts e imagens.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como visualizar

1. Faça o clone ou download do repositório.
2. Abra a pasta da atividade desejada.
3. Execute o arquivo HTML no navegador.

Algumas atividades utilizam arquivos CSS, JavaScript e imagens locais; mantenha a estrutura de pastas ao abrir os arquivos.

## Finalidade

Este repositório funciona como histórico de aprendizagem e prática dos fundamentos de desenvolvimento web ao longo do curso.
